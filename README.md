# Spud Heroes 🥕

**Fun veggie-themed endless runner / arena strategy game** built with Flutter.

Kid-friendly, addictive, and full of personality. A light-hearted game where potatoes, carrots, and tomatoes battle it out!

![Spud Heroes Preview](https://via.placeholder.com/800x450?text=Add+gameplay+screenshots+or+trailer+here)

## Why Spud Heroes?

Most mobile games are either too serious or overly complicated. Spud Heroes brings:
- Simple, fun, colorful gameplay
- Endless runner + light strategy elements
- Cute characters with unique abilities
- Perfect for short play sessions
- Great for kids and casual gamers

## Key Features

- ✅ Endless runner mode with power-ups
- ✅ Arena battles with veggie heroes
- ✅ Multiple characters with special abilities
- ✅ Daily challenges & leaderboards
- ✅ Smooth controls & satisfying animations
- ✅ Ad-supported free version + optional removes

## Tech Stack

- **Flutter** (great for 2D games with Flame engine)
- Flame game engine
- Firebase for leaderboards & cloud saves
- Local storage for offline progress

## Getting Started

```bash
git clone https://github.com/sachin1024-92/spud-heroes.git
cd spud-heroes
flutter pub get
flutter run
```

## Monetization

- Free with rewarded ads & interstitials
- One-time purchase to remove ads
- In-app purchases for character skins / power-ups
- Potential sponsorships for the open-source game engine parts
